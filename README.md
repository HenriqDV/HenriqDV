## 🚀 Projeto em destaque: Controlador de Cultivo Indoor com ESP32

Meu projeto mais completo até agora: um sistema de automação e monitoramento de estufa, construído do zero, do firmware embarcado ao painel web.

- 🌱 Controle de iluminação por **fotoperíodo por fase de cultivo**, com relógio RTC e estado salvo em memória (funciona sem internet)
- 🌡️ Monitoramento de temperatura, umidade, umidade do solo e nível de água
- 🔌 Acionamento de **6 relés** (luz, umidificador, aquecedor, irrigação e outros), com controle de clima por **VPD** com histerese e travas de segurança
- 🌐 **API REST em PHP + MySQL** para leituras, eventos e fila de comandos remotos, com autenticação do dispositivo por token
- 📲 Alertas via **Telegram** e rotinas agendadas (cron)
- 📊 **Painel web em JavaScript** com acompanhamento em tempo real, gráficos de histórico, envio de comandos e exportação em CSV
- 🛡️ Confiabilidade: watchdog, reconexão automática de Wi-Fi, fila de eventos com reenvio e ressincronização de configurações após reinício

Foi meu primeiro projeto integrando embarcado + backend + banco de dados + front-end numa aplicação real, e onde aprendi bastante sobre a comunicação entre hardware e servidor.

**Stack:** ESP32-S3 · C++ · PlatformIO · PHP · MySQL · JavaScript · HTML/CSS · HTTPS/REST · Git

🔗 [github.com/HenriqDV/controlador-cultivo-esp32](https://github.com/HenriqDV/controlador-cultivo-esp32)
